Primeira versão do InputLock para Windows 10/11 x64.

- Bloqueio do teclado, mouse ou ambos.
- Desbloqueio por atalho ou temporizador.
- Atalho de emergência: `Ctrl + Alt + F12`.
- Interface em português, tema escuro e preferências salvas por usuário.

### Downloads

- **InputLock.exe**: portátil. Abra sem instalar.
- **InputLock-Setup.exe**: instalador por usuário.
- **InputLock-Source.zip**: código-fonte desta versão.
- **SHA256SUMS.txt**: checksums dos arquivos.

Não precisa instalar Python. O InputLock bloqueia entradas na sessão atual; para bloquear a sessão do Windows, use `Win + L`.
